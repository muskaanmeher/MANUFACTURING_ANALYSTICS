# MANUFACTURING_ANALYSTICS

I worked on an end-to-end Manufacturing Analytics Project based on a real-world garment manufacturing plant named AXON.The project involved analyzing one year of manufacturing data containing over 10,000 work orders, 86 machines, 10 operations, and 4 departments. The main business problem is to analyst production operations, monitor quality and identify quality-related issues.So,First I used Excel for data cleaning, where I removed 679 blank rows and corrected an incorrectly formatted value in the Operation_Code column.Next, I imported the cleaned data into MySQL and designed a Star Schema consisting of one fact table and eight dimension tables, establishing relationships using primary and foreign keys. I also wrote SQL queries to analyze production, efficiency, machine performance, and rejection rates.After that, I connected the MySQL database to Power BI and Tableau and developed two interactive dashboards. The first was a Production and Efficiency Dashboard for plant managers, while the second was a Quality and Rejection Dashboard for the quality team.During my analysis, I identified that rejection issues were concentrated in certain machines rather than across all departments. Based on this insight, I recommended prioritizing scheduled machine maintenance to improve performance and product quality.Overall, the project improved KPI monitoring, provided actionable insights for management, and reported a 5% reduction in rejection rates.
